# Wiki Ingest

## Overview
raw/의 소스 하나를 읽고 wiki 전체에 통합한다. 페이지 형식·공개 규칙은 CLAUDE.md를 따르고, 이 스킬은 **절차**와 두 가지 판단, 즉 `(보충)` 해소와 비공개 내용 분리를 정한다.

## 1. 읽고 분류
소스를 끝까지 읽고 내용을 세 갈래로 나눈다.

| 갈래 | 예 | 갈 곳 |
|---|---|---|
| 일반 지식 | 책·문서 내용 | 공개 페이지 (backend/data/math/sources) |
| 본인 경험 | 회사·서비스, 수치, 장애·개선 사례 | `career/`만 |
| 개인 기록 | 목표, 회고 | `personal/`만 |

## 2. 승인 요청 (기본)
아래 내용을 보여 주고 **승인 전에는 wiki를 수정하지 않는다.**
- 핵심 내용 3~7개
- 만들거나 고칠 페이지
- `(보충)` 해소 N건 / 새 충돌 M건 (아래 3번 기준)
- 비공개로 분리할 내용이 있는지 (있으면 어느 career/personal 페이지로 갈지)
- 강조할 점 질문

사용자가 승인 생략이나 일괄 처리를 명시하면 이 단계를 건너뛰고, 같은 항목을 5번 보고에 담는다.

## 3. `(보충)` 해소
소스가 다루는 페이지의 `(보충)` 항목을 하나씩 대조한다.

| 소스와의 관계 | 처리 |
|---|---|
| 같은 내용을 담음 | `(보충)` 표시 삭제. 이 소스를 frontmatter `sources`와 `## 출처`에 추가하고, 출처 줄에 뒷받침한 주장을 적는다 |
| 다른 내용을 담음 | `> [!warning] 충돌` 콜아웃에 양쪽을 다 적고, 5번 보고에서 어느 쪽이 맞는지 묻는다 |
| 다루지 않음 | 그대로 둔다 |

해소 과정은 source 페이지의 "기존 wiki와 충돌 / 보완" 절과 log에 기록한다. **개념 페이지에는 해소 사실을 알리는 콜아웃을 달지 않는다.** 독자는 결과만 본다. `> [!note] 갱신됨`은 주장 자체가 새 소스로 바뀌었을 때만 쓴다.

## 4. 반영
1. source 페이지: 일반 지식만 담는다. career/personal 소스라면 해당 폴더에 둔다.
2. 관련 concept/entity 페이지 갱신 (3번 적용)
3. 비공개 내용 → career/personal 페이지. 경험 페이지에서 관련 공개 개념으로 링크한다.
4. 상호 링크
5. `index.md`(공개) 또는 `career-index.md`/`personal-index.md`, 필요하면 `overview.md`
6. `log.md`: 비공개 페이지는 "비공개 페이지 N개"로만 적는다

**공개 페이지의 비공개 흔적은 0이어야 한다.** 공개 페이지(source 페이지 포함)는:
- 본인 경험 페이지(`프로젝트경험` 태그, 경험을 묻는 질문)로 링크하지 않는다. 링크 텍스트가 사이트에 글자로 남기 때문이다.
- 소스에 개인 메모가 있었다거나 그것을 분리했다는 사실을 적지 않는다.
- 일반 면접 질문(개념 질문) 링크는 괜찮다.

## 5. 검증과 보고
- 소스의 고유 표현(서비스명, 수치)으로 공개 경로를 grep해서 0건인지 확인한다:
  `grep -rn "<표현>" wiki/overview.md wiki/backend wiki/data wiki/math wiki/sources wiki/index.md wiki/log.md`
- 새 페이지에 frontmatter가 있는지 확인한다 (없으면 원본 .md가 사이트에 그대로 공개된다)
- 보고 내용: 생성·수정 페이지, `(보충)` 해소 목록, 충돌(사용자 판단 필요), 비공개로 분리한 페이지

## Common Mistakes
| 실수 | 바로잡기 |
|---|---|
| 공개 개념 페이지 "면접 포인트"에 경험 질문 링크 | 경험 페이지 → 개념 페이지 방향으로만 링크 |
| source 페이지에 "개인 메모는 career로 분리" | 아무것도 적지 않는다. 기록은 비공개 페이지와 log의 개수뿐 |
| `(보충)` 해소를 개념 페이지에 콜아웃으로 알림 | source 페이지와 log에만 기록 |
| 충돌을 조용히 한쪽으로 덮어씀 | 양쪽을 남기고 사용자에게 묻는다 |
