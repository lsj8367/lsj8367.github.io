# Redis
> 인메모리 키-값 저장소. 다양한 자료구조와 원자적 연산을 제공해 캐시·랭킹·카운터·분산 락에 쓰인다.

## 개요
- DDIA 1장은 Redis를 "DB로도 메시지 큐로도 쓰이는" 경계가 모호한 도구의 예로 든다.
- (보충) 명령을 **단일 스레드**로 순차 실행하므로 개별 명령(`INCR`, `DECRBY` 등)은 원자적이다. 여러 명령을 묶으려면 **Lua 스크립트**(스크립트 전체가 원자적으로 실행) 또는 `MULTI/EXEC`를 쓴다.

## 주요 특징 / 설정
### 자료구조
| 자료구조 | 특징 | 쓰임 |
|---|---|---|
| String | 기본 key-value 매핑 | 캐시, 카운터 |
| List | 순서 있는 문자열 리스트 | 대기열(큐) |
| Set | 순서 없음, 중복 불허 | 고유 방문자, 태그 |
| Sorted Set | 중복 불허, (보충) **score 기준으로 정렬** | 랭킹 시스템 |
| Hash | 필드-값 맵 | 객체 저장 (Spring Data Redis `@RedisHash`) |

### 사용 사례
- 공유 값의 원자적 차감: 읽고-계산하고-쓰는(read-modify-write) 경쟁 조건은 단일 명령(`DECRBY`)이나, 조건 분기가 필요하면 `GET`과 `DECRBY`를 Lua 스크립트로 묶어 해결한다.
- 분산 락. → [[분산 락 (Distributed Lock)]]
