# 특수 행렬 (Special Matrices)
> 구조적 특징 때문에 계산·분해에서 특별한 역할을 하는 행렬들.

## 핵심
선형대수는 선형계를 **벡터 공간과 행렬**로 표현한다. 아래는 자주 나오는 특수 행렬이다.

| 행렬 | 정의 | 쓰임 |
|---|---|---|
| 정방 행렬(square) | 행 수 = 열 수 | 선형 변환, 고유값 분해 등 많은 연산의 전제 |
| 항등 행렬(identity, I) | 주대각선이 1, 나머지 0인 정방 행렬 | 항등 행렬을 얻으면 변환을 취소하고 원래 기저 벡터를 찾았다는 뜻 |
| 역행렬(inverse, A⁻¹) | 다른 행렬의 변환을 취소하는 행렬. A·A⁻¹ = I | 연립방정식 풀이 |
| 대각 행렬(diagonal) | 주대각선 밖의 원소가 모두 0 | 각 축을 단순히 스칼라배하는 변환을 나타냄 |
| 삼각 행렬(triangular) | 주대각선 한쪽(위 또는 아래)이 모두 0 | 연립방정식을 풀기 쉬워 수치 해석에서 선호. LU 분해에 등장 |
| 희소 행렬(sparse) | 원소 대부분이 0 | 0이 아닌 값만 저장하면 메모리 효율적 |

## 세부 / 동작 방식
- 상삼각 행렬 예:
  $$\begin{bmatrix}4&2&9\\0&1&6\\0&0&5\end{bmatrix}$$
- (보충) 하삼각 행렬은 주대각선 **위쪽**이 모두 0이다. LU 분해는 A를 하삼각(L) × 상삼각(U)으로 나눈다.
- (보충) 대각 행렬은 주대각선 원소가 0이어도 된다. 조건은 "대각선 밖이 모두 0"이다. 원본 노트의 "주대각선에는 0이 아닌 값"은 일반적인 경우를 묘사한 것.
- (보충) 역행렬은 정방 행렬이면서 행렬식(determinant)이 0이 아닐 때만 존재한다.
- 희소 행렬: 노트는 "계산적으로는 좋지 않지만 메모리 측면에서는 좋다"고 정리. (보충) 희소 행렬 전용 저장 형식(CSR 등)과 알고리즘을 쓰면 계산도 빨라진다. 추천 시스템의 사용자-아이템 행렬이 대표적인 예.
