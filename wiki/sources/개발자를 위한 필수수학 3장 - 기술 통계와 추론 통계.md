# 개발자를 위한 필수수학 3장 - 기술 통계와 추론 통계

- 원본: [[raw/개발자를 위한 필수수학/3장. 기술 통계와 추론 통계|3장 노트]]
- 종류: 책 장 (3.5 추론 통계 위주)
- 책: [[개발자를 위한 필수수학 (Essential Math for Data Science)]]

## 요약
중심 극한 정리의 4가지 성질과 표준오차를 Python 시뮬레이션으로 확인했다. 표본이 작으면 t분포를 쓰고, 신뢰 구간으로 추정의 확실성을 표현한다. 모집단을 다 알 수 없으므로 항상 표본 기준으로 생각해야 한다는 중간 정리를 덧붙였다.

## 핵심 주장
- 중심 극한 정리 4가지 성질 (표본 평균의 평균 = 모평균, 정규 모집단이면 정규, n > 30이면 근사적으로 정규, 표준오차 = σ/√n). → [[중심 극한 정리 (Central Limit Theorem)]]
- 30이라는 기준은 통계학 실험으로 정해진 관례. → [[중심 극한 정리 (Central Limit Theorem)]]
- 표준오차 시뮬레이션 코드 (s/√n 평균 ≈ σ/√n). → [[중심 극한 정리 (Central Limit Theorem)]]
- 표본이 31개 미만이면 t분포를 사용. → [[신뢰 구간 (Confidence Interval)]]
- 신뢰 구간은 표본 평균이 모평균의 특정 범위에 속한다고 얼마나 확실하게 믿는지 보여주는 방법. → [[신뢰 구간 (Confidence Interval)]] (해석 보완)
- 중간 정리: 주어진 데이터는 표본이라 가정하고, 표본 평균을 반복해 모집단 성질을 추정한다. → [[중심 극한 정리 (Central Limit Theorem)]]

## 기존 wiki와 충돌 / 보완
- 신뢰 구간 정의는 표현을 보완 (보충): 정확히는 "같은 방법으로 구간을 반복해서 만들면 그중 95%가 모평균을 포함한다"는 뜻이다. → [[신뢰 구간 (Confidence Interval)]]
- 중간 정리의 "표본 평균 표준편차로 모집단 표준편차를 구한다"는 방향은 반대로 쓰는 경우가 많다. 보통은 표본 표준편차 s로 표준오차 s/√n을 추정한다. (보충)
- t분포는 표본이 작을 때뿐 아니라 **모표준편차를 모를 때** 쓴다. (보충)
